# Sessions

A session keeps a user signed in between requests. The store is chosen in ADR-1.

<!-- auth/session#requirements h:c45e6a10f2970c6b spec/active entry -->
## Requirements

- **expiry**: When a session expires, the gateway SHALL reject the request with status 401.
- **renewal**: The session SHALL be renewed quickly, if possible.
- **R-7**: While a session is active, the gateway SHALL refresh its expiry on each request.
- **Bad_Key**: The gateway MUST log the session id.

<!-- auth/session#rationale h:d3002214dbba40b7 spec/active entry -->
## Rationale

Short sessions limit the damage of a stolen cookie. See [the token rules](tokens.md#requirements) and [a missing anchor](tokens.md#nowhere).

<!-- guides/logging#logging h:e819cae7e80b46c9 guide/active applies -->
# Logging

Log every rejected request with its request id and the reason.

# Tokens

<!-- auth/tokens#requirements h:120b874381208450 spec/deprecated depends -->
## Requirements

- **signing**: The issuer SHALL sign every token with Ed25519.
- **lifetime**: If a token is older than 15 minutes, the gateway SHALL reject it.
