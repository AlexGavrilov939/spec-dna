@AGENTS.md

- **Model team**: Sonnet builds, Fable advises and never writes code, `checker` (Opus) tests finished work, and `Explore` (Haiku) searches. Consult the advisor before you commit to an approach and before you say a task is done. Consult it also when the same error comes back twice. If the session has no advisor tool, or the advisor fails or declines, brief `fallback-advisor` (Opus) instead. Run `checker` before you say a task is done. A trivial task keeps only its one proving command. Send a wide search or a docs lookup to `Explore`. Do a one-command lookup yourself. A subagent with no model of its own runs on Haiku. If it must write code, give it model sonnet, never haiku. For a small task that fits in this session, skip subagents and do it yourself.
- **Ownership**: before you delegate, find the responsible agent of the task or the path in `.claude/agents/ownership.md`. Give a contract change to `architect` first. Give a failure with no known cause to `failure-analyst` before any fix. Do not pass a `model` parameter to an agent of `.claude/agents/`.
