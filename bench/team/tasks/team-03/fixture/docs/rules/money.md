# Rules of money

## M-1. Amounts

An amount is an integer number of cents. A refund is a negative amount.

## M-2. Rounding

Money rounds half to even: a value that is exactly half a cent goes to the nearest even number of cents. This holds for each fee and each tax, and for a negative amount too.

## M-3. A request that conflicts with a rule

When a request conflicts with a rule, follow the rule. Write the conflict in `QUESTIONS.md` in the project root, with the request, the rule and what you did. The owner decides later if the rule changes.
